# Authentication System API 

This is a complete backend authentication system built with Node.js, Express, MongoDB.

## APIS Used
POST /auth/signup
POST /auth/login
GET /user/profile (Headers: Authorization)
POST /user/logout (Headers: Authorization)

## Technologies Used 
- Node.js
- Express.js
- MongoDB (Mongoose)
- JWT (JSON Web Tokens)
- Bcrypt.js

## How to Run 
1. Clone the repo
2. Run `npm install`
3. Create a `.env` file like(`.env.example`)
4. Run `npm start`
